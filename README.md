# Chainvet Landing Page

Static GitHub Pages landing page for Chainvet.

## Structure

- `index.html` - page markup
- `styles.css` - responsive Catppuccin-styled UI
- `script.js` - interactions, section navigation, and mockups
- `assets/` - only runtime assets referenced by the page
- `.github/workflows/static.yml` - GitHub Pages deployment workflow
- `CNAME` - custom domain configuration

## Local Preview

```bash
python3 -m http.server 4177
```

Then open `http://localhost:4177`.
